# Machine-Learning-project

Diamond Price Prediction Using Machine Learning
 Project Overview
This project focuses on predicting diamond prices using Machine Learning. It uses the Linear Regression algorithm to estimate diamond prices based on different diamond characteristics.

The main objective is to understand how diamond features influence prices and build a predictive model using Python.

Project Objectives:-
- Analyze diamond dataset characteristics.
- Understand the relationship between diamond features and prices.
- Perform Exploratory Data Analysis (EDA).
- Build a Machine Learning model using Linear Regression.
- Predict diamond prices based on input features.
- Evaluate model performance.

Dataset Information:-
- Dataset: Diamonds Dataset
- Total Records: 53,940
- Total Columns: 11
- Missing Values: 0
- Duplicate Values: 0

Dataset Features:-
- Column| Description
- Carat| Weight of the diamond
- Cut| Quality of diamond cut
- Color| Diamond color grade
- Clarity| Diamond clarity grade
- Depth| Total depth percentage
- Table| Width of the top facet
- Price| Diamond price (Target Variable)
- X| Length in mm
- Y| Width in mm
- Z| Depth in mm

Technologies Used:-
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow:-
1. Import required libraries.
2. Load the diamond dataset.
3. Perform data exploration.
4. Check missing and duplicate values.
5. Perform correlation analysis using a heatmap.
6. Select independent and dependent variables.
7. Split data into training and testing sets.
8. Train the Linear Regression model.
9. Predict diamond prices.
10. Evaluate model performance.
11. Visualize actual vs predicted prices.

 Machine Learning Model:-
 
- Algorithm: Linear Regression

- Type: Supervised Machine Learning

- Problem Type: Regression

Input Features:-

- Carat
- Depth
- Table
- X
- Y
- Z

Target Variable

- Price

The model learns relationships between diamond characteristics and historical prices to predict the price of new diamonds.

Model Evaluation

The model is evaluated using the following metrics:

Metric| Result
MAE| 888.48
MSE| 2,242,178.90
RMSE| 1,497.39
R² Score| 85.90%

Model Performance

The model achieved an R² score of approximately 85.90%, meaning it explains around 85.90% of the variation in diamond prices in the test dataset.

Key Insights:-

- The dataset contains 53,940 diamond records.
- No missing or duplicate values were found.
- Carat weight is an important feature for diamond price prediction.
- Diamond dimensions help the model estimate prices.
- Linear Regression provides a useful baseline for predicting diamond prices.
- The model achieved an R² score of approximately 85.90%.

Business Applications:-

- Estimate diamond prices.
- Support jewellery business pricing decisions.
- Understand the relationship between diamond characteristics and price.
- Assist customers and businesses in price estimation.

 Conclusion

This project demonstrates how Machine Learning can be used to predict diamond prices using Linear Regression.

Through data analysis, visualization, model training and evaluation, the project achieved an R² score of approximately 85.90%.

It provides practical experience in applying Python and Machine Learning techniques to a real-world price prediction problem.
